# Topological Sort

Characteristics:

- Works only on DAGs (no cycles allowed)
- Produces a linear ordering of vertices
- Can have multiple valid orderings for the same graph
- Often implemented using Depth-First Search (DFS) or Kahn's algorithm

Topological Sort is useful because it helps solve dependency-related problems efficiently, especially in scenarios where tasks must be executed in a specific order based on their relationships.
