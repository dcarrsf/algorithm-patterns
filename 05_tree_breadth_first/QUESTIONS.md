# Practice Questions: Tree Breadth-First Search

Types of questions that prompt using each example:

- **Level Order Traversal**: "Given the root of a binary tree, return the level order traversal of its nodes' values."

- **Minimum Depth**: "Given a binary tree, find its minimum depth (the number of nodes along the shortest path from the root node down to the nearest leaf node)."

- **Zigzag Level Order**: "Given the root of a binary tree, return the zigzag level order traversal of its nodes' values."

- **Find Nearest Right Node**: "Given the root of a binary tree and a node u in the tree, return the nearest right node of u, or null if u is the rightmost node in its level."
