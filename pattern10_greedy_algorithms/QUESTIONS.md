# Practice Questions: Greedy Algorithms

Types of questions that prompt using each example:

1. **Coin Change**: "Given a set of coin denominations, find the minimum number of coins needed to make a certain amount."

2. **Activity Selection**: "Schedule the maximum number of non-overlapping events given their start and end times."

3. **Fractional Knapsack**: "Maximize the value of items you can carry in a knapsack with a weight limit, allowing for fractional items."

4. **Huffman Coding**: "Design an optimal prefix code for compressing data given character frequencies."
