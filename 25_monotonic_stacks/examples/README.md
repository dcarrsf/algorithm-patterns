# Examples: Monotonic Stack

The key characteristics of a monotonic stack are:

- It's a stack (last-in-first-out data structure)
- Elements are pushed and popped to maintain monotonicity (either increasing or decreasing order)
- It allows for efficient lookup of the nearest greater/smaller elements

Monotonic stacks are useful because they can solve certain types of problems in linear time complexity (O(n)), which might otherwise require nested loops and quadratic time complexity (O(n^2)).
