# Practice Questions: Tree Depth First Search

Types of questions that prompt using each example:
1. **Pre-order Traversal**: "Given a binary tree, return the pre-order traversal of its nodes' values."

2. **Path Sum**: "Given the root of a binary tree and an integer targetSum, return true if the tree has a root-to-leaf path such that adding up all the values along the path equals targetSum."

3. **Maximum Depth**: "Given the root of a binary tree, return its maximum depth."

4. **All Paths**: "Given the root of a binary tree, return all root-to-leaf paths in any order."

5. **Post-order Tracersal**: "Given the root of a binary tree, return the post-order traversal of its nodes' values."
