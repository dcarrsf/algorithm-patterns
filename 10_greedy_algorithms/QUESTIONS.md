# Practice Questions: Greedy Algorithms

Types of questions that prompt using each example:

1. **Coin Change**: "Given a set of coin denominations and a target amount, find the minimum number of coins needed to make up that amount."

2. **Activity Selection**: "Given a set of activities with start and end times, find the maximum number of non-overlapping activities that can be performed."

3. **Fractional Knapsack**: "Given a set of items with weights and values, and a knapsack with a maximum weight capacity, find the maximum value that can be put into the knapsack."

4. **Huffman Coding**: "Given a set of characters and their frequencies, construct a binary tree that represents the optimal prefix code for compressing the data."
