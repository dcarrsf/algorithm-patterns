# Practice Questions: In-Place Manipulation of Linked List

Types of questions that prompt using each example:

1. **Reversing**: "Reverse the order of nodes in a linked list."

2. **Cycle Detection**: "Determine if a linked list contains a cycle."

3. **Reordering**: "Reorder the list to L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …"

4. **Removing Nth from End**: "Remove the nth node from the end of the list and return its head."
