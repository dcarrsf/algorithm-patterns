# Practice Questions: Two Heaps

Types of questions that prompt using each example:

"Find the Median from a Data Stream" is used when you need to find the median of a constantly growing dataset.
"Sliding Window Median" is used when you need to find medians of subarrays of a fixed size in a larger array.
"Find the Kth Largest Element in a Stream" is used when you need to maintain the kth largest element in a growing dataset.
"Find the Median of Two Sorted Arrays" is used when you need to efficiently find the median of two separate sorted arrays without merging them.
