# Practice Questions: Trie

Types of questions that prompt using each example:

1. **Basic Trie**: "Implement a data structure for storing and searching words efficiently."

2. **Autocomplete Trie**: "Design a system to provide autocomplete suggestions as a user types."

3. **Word Search Trie**: "Given a 2D board of characters and a list of words, find all words from the list that can be formed on the board."

4. **IP Routing Trie**: "Implement an IP routing table with efficient longest prefix matching for packet forwarding."
