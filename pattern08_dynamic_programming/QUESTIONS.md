# Practice Questions: Dynamic Programming

Types of questions that prompt using each example:

1. **Maximum Subarray Sum**: "Find the contiguous subarray with the largest sum."

2. **Longest Increasing Subsequence**: "Find the length of the longest subsequence where all elements are in increasing order."

3. **Coin Change**: "What's the minimum number of coins needed to make up a certain amount?"

4. **Climbing Stairs**: "In how many distinct ways can you climb to the top if you can take 1 or 2 steps at a time?"

5. **0/1 Knapsack Problem**: "Given a set of items with weights and values, find the maximum value you can carry in a knapsack of limited weight capacity."

6. **Longest Common Subsequence**: "Find the length of the longest subsequence present in both given sequences."

7. **Edit Distance**: "Find the minimum number of operations required to convert one string to another."

8. **Palindromic Substrings**: "Count how many palindromic substrings are in the given string."
