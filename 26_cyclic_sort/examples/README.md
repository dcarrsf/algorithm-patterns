# Examples: Cyclic Sort

The key characteristics of Cyclic Sort are:

- It's in-place, meaning it doesn't require extra space proportional to the input size.
- It has a time complexity of O(n), making it very efficient for its specific use case.
- It's particularly effective when the range of numbers is known and closely related to the array size.

Cyclic Sort is useful because it can solve certain types of problems in linear time and constant space, which is optimal for many array-related questions.
