# Practice Questions: Bitwise XOR

Overview:

1. **[Single Number](#1-single-number)**: Given a non-empty array of integers, every element appears twice except for one. Find that single one.
2. **[Missing Number](#2-missing-number)**: Given an array containing n distinct numbers taken from 0, 1, 2, ..., n, find the one that is missing from the array.
3. **[Find the Difference](#3-find-the-difference)**: Given two strings s and t which consist of only lowercase letters. String t is generated by random shuffling string s and then add one more letter at a random position. Find the letter that was added in t.
4. **[Swap Numbers](#4-swap-numbers)**: Swap two numbers without using a temporary variable.

Details:

## 1. **Single Number**

**Question**: "We have an array of integers where every element appears twice except for one. Can you write a function to find that single element? The catch is, you need to do this with linear time complexity and without using any extra space."

Input:

```javascript
const nums = [4, 1, 2, 1, 2];
```

Expected Output:

```javascript
4
```

Additional Information:

The array will always have an odd number of elements, and every element will appear exactly twice except for one.


## 2. **Missing Number**

**Question**: "Given an array containing n distinct numbers taken from the range 0 to n, can you find the missing number? Your solution should run in linear time and use only constant extra space."

Input:

```javascript
const nums = [3, 0, 1];
```

Expected Output:

```javascript
2
```

Additional Information:

The range of numbers is from 0 to n, where n is the length of the input array. The array will contain n distinct numbers from this range, with one number missing.


## 3. **Find the Difference**

**Question**: "We have two strings, s and t. String t is generated by randomly shuffling string s and then adding one more letter at a random position. Can you write a function to find and return the letter that was added to t?"

Input:

```javascript
const s = "abcd";
const t = "abcde";
```

Expected Output:

```javascript
"e"
```

Additional Information:

Both strings contain only lowercase letters. String t will always be one character longer than string s.


## 4. **Swap Numbers**

**Question**: "Can you write a function that swaps two numbers without using a temporary variable? Your function should take two numbers as input and return an array with the swapped numbers."

Input:

```javascript
let a = 5;
let b = 10;
```

Expected Output:

```javascript
[10, 5]
```

Additional Information:

You're not allowed to use any additional variables or array elements beyond what's provided in the function parameters and return value.
