# Practice Questions: Top K Elements

Types of questions that prompt using each example:

1. **K Largest Elements**: "Find the K largest elements in an unsorted array."

2. **K Most Frequent Elements**: "Given an integer array, return the K most frequent elements."

3. **Kth Largest Element**: "Find the Kth largest element in an unsorted array."

4. **K Closest Points to Origin**: "Given an array of points in a 2D plane, find K closest points to the origin."
