# Practice Questions: Fast and Slow Pointers

Types of questions that prompt using each example:

1. **Detect Cycle**: "Given a linked list, determine if it has a cycle in it."

2. **Find Middle**: "Find the middle element of a linked list in one pass."

3. **Determine if Array is Circular**: "Check if an array is circular (i.e., it repeats itself)."

4. **Find Start of Cycle**: "Given a linked list with a cycle, return the node where the cycle begins."
